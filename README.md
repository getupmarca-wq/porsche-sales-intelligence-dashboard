# 🏎️ Porsche Sales Overview — Sales Intelligence Dashboard

An interactive sales dashboard built with **HTML, CSS, and JavaScript** to explore Porsche vehicle sales data, analyze revenue, and compare sales performance across locations, models, and vehicle years.

## 📊 Project Overview

The Porsche Sales Overview dashboard provides a visual interface for analyzing sales records through dynamic filters, KPI cards, charts, and a detailed sales table.

The project demonstrates how web technologies can transform structured sales data into an interactive business intelligence experience.

## ✨ Features

### 📌 Key Performance Indicators (KPIs)
- **Total Revenue:** Sum of valid sales prices.
- **Vehicles Sold:** Number of records matching the selected filters.
- **Average Ticket:** Average price for sales with valid prices.
- **States / Models:** Coverage of locations and Porsche models in the filtered data.

### 📈 Interactive Charts
- **Revenue by State:** Highlights locations with the highest revenue.
- **Performance by Model:** Compares revenue across Porsche models.
- **Sales Trend:** Displays monthly revenue using records with valid dates.
- **Vehicle Year Distribution:** Shows the number of vehicles by model year.

### 🔎 Dynamic Filters
- Filter sales by state.
- Select a Porsche model.
- Filter by vehicle year.
- Search by city or sale ID.
- Reset all filters to return to the complete dataset.

### 📋 Sales Breakdown
A detailed table displays:
- Sale ID
- Sale date
- Porsche model
- Vehicle year
- City
- State
- Selling price

Records with invalid dates remain visible in the sales table but are excluded from the monthly trend chart.

## 🛠️ Technologies Used

- **HTML5** — Dashboard structure.
- **CSS3** — Layout, styling, and responsive interface.
- **JavaScript** — Data filtering, KPI calculations, chart rendering, and table updates.
- **HTML Canvas** — Rendering the charts directly in the browser.

## 🚀 How to Run

1. Clone or download this repository.
2. Locate the `dashboard_porsche_sales_overview.html` file.
3. Open the HTML file in a modern web browser.
4. Use the filters and search field to explore the sales data.

No backend server or external JavaScript library is required for the dashboard to run locally.
